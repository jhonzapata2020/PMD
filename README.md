## 🌟 Características Principales

1. **Formulario 1 - Nuevos Asociados:**
   - Registro de nombres, apellidos, documento (CC, PPT, CE, Pasaporte), contacto, departamento, municipio y dirección.
   - Validación y autorización de Habeas Data según la Ley 1581 de 2012.
2. **Formulario 2 - Asociados Existentes y Cuenta Internacional:**
   - Actualización de datos y registro de cuenta exterior (IBAN, banco, país, código SWIFT/BIC).
3. **Emisión de Certificado Oficial en Pop-up:**
   - Generación de certificado de adscripción y membresía con membrete oficial, folio institucional, firma digital y código QR.
   - Descarga directa en **PDF** e **Impresión** optimizada.
4. **Panel Administrativo con Seguridad:**
   - Acceso con credenciales administrativas (`admin@pmdsas.org` o `empresasmussa2000@gmail.com` / `Pmd2026*`).
   - Visualización de registros en tiempo real, búsqueda y filtrado.
   - Exportación de listados a **Excel / CSV**.
   - Reimpresión de certificados individuales.
   - Script SQL de Supabase integrado listo para ejecutar.

## 🚀 Despliegue en Vercel

1. Sube este repositorio a GitHub.
2. Ingresa a [Vercel](https://vercel.com) e importa el repositorio `PMD`.
3. Framework Preset: **Vite**.
4. (Opcional) En *Environment Variables*, añade:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. Haz clic en **Deploy**.
